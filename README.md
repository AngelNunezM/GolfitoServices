# Activar cli Tailwind
npx @tailwindcss/cli -i Public/css/input.css -o Public/css/output.css --watch

# Levantar el servidor local
Es necesario tener instalado php 8.2 en el path de el equipo para poder utilizar el comando que se 
proporciona a continuación: php -S localhost:5000 -t Public

este archivo se encuentra en la carpeta Public y es el que se encarga de levantar el servidor local para poder visualizar la aplicación en el navegador.
